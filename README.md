# HRDcases
İKY yüksek lisans, Eğitim ve Geliştirme dersi vaka arşivi.

## Yeni vaka eklemek
1. Yeni bir klasör açın (küçük harf, Türkçe karakter ve boşluk olmadan, örn. `yetiskin-ogrenme`).
2. Vaka sayfasını bu klasöre `index.html` adıyla koyun.
3. Kök dizindeki `index.html` dosyasına yeni bir `<a class="case">` bloğu ekleyin.
4. Commit edin. 1-2 dakika içinde yayına girer.
